Decimal to BCD Priority Logic Equations

When water touches higher sensors, lower sensors remain submerged. The priority encoder takes the highest active input index and suppresses lower inputs.

Q0 (1) = S1·S2'·S4'·S6'·S8' + S3·S4'·S6'·S8' + S5·S6'·S8' + S7·S8' + S9
Q1 (2) = S2·S4'·S5'·S8'·S9' + S3·S4'·S5'·S8'·S9' + S6·S8'·S9' + S7·S8'·S9'
Q2 (4) = S4·S8'·S9' + S5·S8'·S9' + S6·S8'·S9' + S7·S8'·S9'
Q3 (8) = S8 + S9

BCD to 7-Segment Decoder Functions

The 74HC4511 converts 4-bit BCD into 7 individual LED segment control signals ($a$ through $g$).

a = Q3 + Q1 + (Q2 ⊙ Q0)
b = Q2' + (Q1 ⊙ Q0)
c = Q2 + Q1' + Q0
d = Q3 + (Q2' · Q0') + (Q1 · Q0') + (Q2' · Q1) + (Q2 · Q1' · Q0)
e = (Q2' · Q0') + (Q1 · Q0')
f = Q3 + Q2 + (Q1' · Q0')
g = Q3 + (Q2 · Q1') + (Q2' · Q1) + (Q1 · Q0')
